# IEEE PSL (VHDL) Formatter

This extension implements simple formatting and syntax highlighting for IEEE PSL language (VHDL flavor).

Files with the `.psl` extension are automatically assigned to this extension.


## Extension Settings

* `pslVhdlFormatter.alignOperator`: align the temporal operators.
* `pslVhdlFormatter.indentSize`: set the number of spaces for indentation.
* `pslVhdlFormatter.maxLineLength`: set the maximum line length.
